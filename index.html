          Sync zwischen Geräten

          Gleicht deine Daten automatisch über GitHub ab – z. B. zwischen PC und Handy. Dafür trägst du auf jedem Gerät einmal einen GitHub-Token ein.

          So bekommst du einen Token
          1. Auf github.com oben rechts auf dein Profilbild → Settings.
          2. Links ganz unten Developer settings → Personal access tokens → Fine-grained tokens.
          3. Generate new token: Name z. B. „Vokabel-App“, Ablaufdatum wählen.
          4. Bei den Berechtigungen nur Gists auf Read and write stellen – sonst nichts.
          5. Generate token und den Token sofort kopieren – GitHub zeigt ihn nur einmal.

          Backup

          Speichert alle Fächer, Decks, Karten und deinen Lernfortschritt in einer Datei. Damit sicherst du deine Daten – oder überträgst sie auf ein anderes Gerät.
